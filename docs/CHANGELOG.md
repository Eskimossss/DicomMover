# История изменений DicomMover

## Версия 1.5

Дата выпуска: 03.09.2026

### Добавлено

- Мастер отправки сохранённых исследований на новый или дополнительный PACS из настроек выбранного сервера.
- Фильтры мастера по наблюдаемой папке, диапазону Study Date и Modality, предварительный расчёт количества и размера файлов, защита от повторного создания доставок.
- Команда **Решить проблему** для неоднозначной кодировки с выбором разового решения либо постоянного правила.
- Сохранение разового решения кодировки в SQLite до успешного завершения C-STORE.
- Необязательные условия правил кодировки по Modality, Station Name и Manufacturer с поиском доступных значений без загрузки Pixel Data.
- Фильтр сводки по PACS.
- Настраиваемая задержка удаления пустых подпапок от 5 до 1440 минут.
- Проверка дубликатов PACS по сочетанию адреса, порта и Called AE Title.

### Изменено

- Сводка теперь считает отдельные доставки на PACS, уникальные исследования, ошибки и фактические попытки отправки.
- Поле задержки удаления подпапок доступно только при включённой очистке.
- Журнал главного окна ограничен 2 000 последними строками и использует виртуализацию элементов.
- Мастер отправки истории получил светлую читаемую тему и подтверждение массовой операции.
- Сообщения о количестве исследований используют правильные формы слов: «исследование», «исследования», «исследований».
- В окне «О программе» отображается версия `1.5` и добавлена ссылка для связи с разработчиком.

### Исправлено

- Таймаут отдельного C-STORE больше не объявляет весь PACS недоступным.
- Штатное завершение приложения во время отправки возвращает доставку в очередь без расходования попытки.
- Ответы PACS C-STORE корректно разделяются на успех, предупреждение и отказ; предупреждение считается успешной доставкой, отказ — ошибкой конкретной доставки.
- Временно недоступные, заблокированные и изменяющиеся файлы больше не перемещаются в `BAD`.
- Повреждённый DICOM переносится в `BAD` только после трёх последовательных стабильных подтверждений.
- Ошибка доступа к одной подпапке больше не прерывает обход остальных каталогов.
- Ложное объявление `ISO_IR 100` исправляется только явным правилом или разовым решением инженера.
- Проблема кодировки закрывается только после успешного C-STORE.

### Производительность и надёжность

- Перекодирование выполняется через защищённый временный файл в `%LOCALAPPDATA%\DicomMover\Temp`, который удаляется после попытки отправки.
- Производственная проверка временного DICOM использует `FileReadOption.SkipLargeTags`, поэтому Pixel Data не загружается повторно в память.
- Добавлены проверка свободного места и очистка оставшихся временных файлов предыдущих запусков.
- Добавлены индексы SQLite для очереди, доставок, активных проблем и отклонённых файлов.
- Отложенное удаление пустых каталогов защищает недавно изменённые и служебные папки от преждевременной очистки.

## Версия 1.4

Дата выпуска: 15.08.2026

### Добавлено

- Вкладка «Активные проблемы» с полным описанием ошибок, временем возникновения, рекомендуемыми и контекстными действиями.
- Учёт недоступных PACS и наблюдаемых папок, некорректных DICOM-файлов в `BAD`, исчерпанных попыток отправки и ошибок перекодировки.
- Сводка отправки за выбранную дату или период с детализацией по файлам и PACS.
- Независимая периодическая проверка доступности PACS и расширенное журналирование DICOM C-ECHO.
- Диагностика DICOM-текста, проверка преобразования и просмотр подробностей отдельных DICOM-элементов.
- Управляемые правила безопасной перекодировки DICOM-текста для конкретной пары «папка → PACS».
- Необязательные условия правил по Modality `(0008,0060)`, Station Name `(0008,1010)` и Manufacturer `(0008,0070)` с автоматическим поиском значений в папке.
- Поддержка нескольких правил для одной пары «папка → PACS» с выбором наиболее специфичного подходящего правила.
- Фильтры по Modality и Station Name в окнах диагностики и проверки преобразования.
- Проверка наличия новой версии через GitHub из окна «О программе».

### Изменено

- Перекодированный DICOM создаётся отдельно только для отправки: исходный файл и его Pixel Data остаются неизменными.
- Преобразование останавливается, если целевая кодировка не может представить текст без потери символов.
- Для диагностики и выбора правила DICOM-метаданные читаются без загрузки Pixel Data, что уменьшает потребление памяти.
- Улучшены главное окно, настройки, вкладки, таблицы и полосы прокрутки; высоту журнала теперь можно регулировать.
- Версия приложения и сборки обновлена до `1.4.0`; в интерфейсе показывается `1.4`.

## Версия 1.3

Дата выпуска: 06.08.2026

### Добавлено

- Современное компактное главное окно со счётчиками очереди, успешных отправок и ошибок.
- Поиск по ФИО, имени и пути файла, UID, модальности и тексту ошибки; отдельные фильтры статуса и PACS.
- Сворачиваемый журнал с фильтрацией по уровню и индикатором новой ошибки или предупреждения.
- Настройки папок и PACS со списком элементов слева и карточкой выбранного элемента справа.
- Пояснения для таймаутов PACS и параметров обработки подпапок.
- Экран первоначальной настройки и блокировка запуска до добавления папки и PACS.
- Подтверждение удаления папки или PACS и предупреждение о несохранённых настройках.
- Окно «О программе» с версией, расположением SQLite и папки журналов.
- Автозаполнение Calling AE значением `DICOMMOVER` для нового PACS.
- Самодостаточная portable-публикация одним EXE без отдельной установки .NET Desktop Runtime.

### Изменено

- В шапке оставлено только название DicomMover без пометки preview.
- Счётчики папок и PACS убраны как дублирующие быстрое управление.
- Настройки папок и PACS при первом запуске создаются пустыми и заполняются пользователем.
- Версия приложения и сборки обновлена до `1.3.0`; в интерфейсе показывается `1.3`.
- Release-сборка больше не публикует отладочный файл PDB.

### Исправлено

- Выбранная папка архива сразу отображается в соответствующем поле.
- Индикатор новой проблемы отображается при ошибке в свёрнутом журнале.
- Устранено аварийное завершение при первом запуске из-за раннего события фильтра PACS.

## Версия 1.2

Дата выпуска: 02.08.2026

### Добавлено

- Подробное окно DICOM-экземпляра с SOP Instance UID, путём, ФИО, Patient ID, датой рождения, модальностью, Study Instance UID, Accession Number и Study Date.
- Таблица независимых результатов доставки на каждый PACS с числом попыток, временем и последней ошибкой.
- Повторная отправка выбранной неуспешной доставки на конкретный PACS.
- Контекстное меню очереди: подробности, повтор отправки, расположение файла, копирование ошибки и скрытие записи.
- Реальный C-ECHO всех включённых PACS в отчёте проверки перед ручным запуском.
- Панель текущего состояния папок и PACS с временной паузой отдельных направлений.
- Перенос некорректных или неподдерживаемых файлов в папку `BAD` внутри корня импорта.
- Фильтр каждой наблюдаемой папки по DICOM Study Date `(0008,0020)`.
- Дополнительные DICOM-метаданные: Patient ID, дата рождения, модальность, Study UID, Accession Number и дата исследования.
- Поиск по файлу, ФИО, UID, модальности и ошибке; фильтры по статусу и PACS.
- Цветной индикатор статуса и выбор отображаемых столбцов с сохранением ширины.
- Суточная статистика найденных, отправленных и ошибочных записей.
- Проверка пересечения корневых папок при сохранении конфигурации.
- Ежедневные резервные копии SQLite и настраиваемый срок их хранения.
- Опциональная еженедельная проверка целостности и оптимизация SQLite.
- Экспорт и импорт настроек, ручное создание резервной копии SQLite.
- Компактная таблица отправленных SOP Instance UID, сохраняющая дедупликацию после очистки подробной истории.
- Защита от одновременного запуска двух экземпляров программы.
- Корректная остановка при завершении работы Windows.
- Набор автоматических тестов расширен до миграций, очереди, дедупликации, восстановления, фильтра даты, резервного копирования и повторов доставки.

### Изменено

- При полной недоступности PACS или сети попытка файла больше не расходуется; C-ECHO повторяется примерно раз в минуту до восстановления связи.
- Для ошибок C-STORE применяется прогрессивный график повторов: 1, 5, 15 и 30 минут; после пятой ошибки автоматические повторы прекращаются.
- Повтор уже успешно выполненной доставки не создаётся, а причина записывается в журнал.
- Кнопка в подробностях переименована в **Повторить отправку на PACS**.
- Настройки столбцов, сроков хранения и обслуживания SQLite вынесены в интерфейс.
- История SQLite автоматически сокращается, а реестр SOP UID остаётся для защиты от дубликатов.
- Версия приложения и сборки обновлена до `1.2.0`.

### Исправлено

- Недоступность одного PACS больше не расходует лимит автоматических попыток всех файлов.
- Уже находившиеся в SQLite записи корректно учитывают изменённый фильтр Study Date.
- Отмена операции не отображается как ошибка отправки.
- Ошибки остановки мониторинга больше не подавляются без журнала и уведомления.
- Повторная отправка из подробностей теперь явно сообщает результат действия.

## Версия 1.1

Дата выпуска: 02.08.2026

### Добавлено

- Поддержка нескольких наблюдаемых папок.
- Поддержка нескольких PACS с отдельным выбором направлений для каждой папки.
- Отдельное окно настроек для папок, PACS, мониторинга, автозапуска и журналирования.
- Варианты обработки успешно отправленного файла: оставить, удалить или перенести в архив.
- Сохранение структуры подпапок при архивировании и удаление пустых вложенных каталогов.
- Отображение ФИО пациента из тега Patient Name `(0010,0010)`.
- Дедупликация по SOP Instance UID.
- Автозапуск вместе с Windows, автоматический старт мониторинга и системный трей.
- Ежедневные файлы журналов и автоматическая очистка старых логов.
- Настраиваемое время отображения успешных записей и журнала в интерфейсе.
- Диалог очистки истории с выбором успешных либо всех записей.
- Регулируемая высота области журнала.
- Кнопки очистки видимого журнала и открытия папки журналов.
- Фирменный логотип и иконка приложения.

### Изменено

- Интервал проверки папок по умолчанию увеличен до 45 секунд.
- Рабочие данные перенесены в переносимую структуру рядом с приложением: `data`, `logs` и `backups`.
- Настройки во время мониторинга применяются через безопасный перезапуск с отдельной копией конфигурации.
- SQLite `busy_timeout` применяется к каждому соединению.
- Количество автоматических попыток ограничено пятью.
- Параметры интервалов и таймаутов валидируются.
- Успешные записи автоматически скрываются из интерфейса через заданный срок без немедленного удаления данных SQLite.

### Исправлено

- Недоступная подпапка больше не прерывает сканирование остальных каталогов.
- Повреждённые настройки, недоступный каталог журналов и ошибки SQLite обрабатываются при запуске.
- Любой файл больше не принимается за DICOM без проверки структуры.
- Отмена мониторинга не превращается в ошибку отправки.
- Исправлено отображение русских ФИО при отсутствии Specific Character Set за счёт резервной кодировки Windows-1251.
- Ошибка завершения мониторинга теперь записывается в журнал и показывается оператору.

## Версия 1.0

Дата выпуска: 30.07.2026

### Первая официальная версия DicomMover

#### Добавлено

- Графический интерфейс WPF.
- Мониторинг выбранной папки.
- Проверка PACS через DICOM C-ECHO.
- Автоматическая отправка файлов по DICOM C-STORE.
- Очередь отправки на базе SQLite.
- Защита от повторной отправки файлов.
- Автоматические повторные попытки при ошибках.
- История отправки.
- Журнал работы.
- Сохранение исходных файлов после успешной отправки.
