# Версия 1.0

Дата выпуска: 30.07.2026

## Первая официальная версия DicomMover

### Добавлено

- Графический интерфейс WPF.
- Мониторинг выбранной папки.
- Проверка PACS через DICOM C-ECHO.
- Автоматическая отправка файлов по DICOM C-STORE.
- Очередь отправки на базе SQLite.
- Защита от повторной отправки файлов.
- Автоматические повторные попытки при ошибках.
- История отправки.
- Журнал работы.
- Сохранение исходных файлов после успешной отправки.
