# Roadmap DicomMover

Roadmap отражает основные направления развития проекта. Подробный состав уже
выпущенных версий находится в [CHANGELOG.md](CHANGELOG.md).

## Версия 1.0 ✅

- [x] Графический интерфейс WPF
- [x] Мониторинг папки
- [x] Очередь отправки на базе SQLite
- [x] Проверка PACS через DICOM C-ECHO
- [x] Отправка файлов через DICOM C-STORE
- [x] Логирование и защита от повторной отправки
