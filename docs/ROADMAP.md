# Roadmap DicomMover

Roadmap отражает основные направления развития проекта. Подробный состав уже
выпущенных версий находится в [CHANGELOG.md](CHANGELOG.md).

## Версия 1.0 ✅

- [x] Графический интерфейс WPF
- [x] Мониторинг папки
- [x] Очередь отправки на базе SQLite
- [x] Проверка PACS через DICOM C-ECHO
- [x] Отправка файлов через DICOM C-STORE
- [x] Логирование и защита от повторной отправки

## Версия 1.4 — предварительный план

Основная тема версии — быстрое обнаружение и устранение эксплуатационных проблем.

- [ ] Статус мониторинга и количество проблем в подсказке системного трея
- [ ] Команды запуска, остановки и открытия настроек в меню системного трея
- [ ] Отдельные уведомления о недоступности и восстановлении PACS
- [x] Вкладка «Активные проблемы» с единым списком проблем, требующих внимания
- [ ] Отображение доставок с исчерпанными попытками и действие повторной отправки
- [ ] Отображение некорректных файлов, перемещённых в `BAD`
- [ ] Обнаружение недоступных наблюдаемых папок во время работы
- [ ] Время, причина и подходящее действие для каждой проблемы
