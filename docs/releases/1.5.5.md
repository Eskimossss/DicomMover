DicomMover 1.5.5 — автономная portable-сборка для Windows x64. Отдельная установка .NET не требуется.

## Период отправки с датой и временем

В **Настройки → Папки** обе границы расположены в одной строке: **С … До …**. Например, с `23.11.2026 11:30` до `25.11.2026 08:00`.

- Календарь и выбор часов/минут открываются вместе. Произвольный текст во время вводить нельзя.
- «Сбросить» убирает соответствующую границу. Можно задать только начало или только окончание.
- Флажок «Указать время» включает точное время. Без него учитываются начало дня для «С» и конец дня для «До».
- Обе границы включаются. Время без секунд означает `:00` секунд.
- Используются DICOM Study Date `(0008,0020)` и Study Time `(0008,0030)`. Если достоверного времени нет, исследование проходит только тогда, когда весь день входит в период.
- Ограничение применяется к новым файлам и накопленной очереди при запуске мониторинга. Для старых записей время считывается из исходного DICOM без изменения файла.
- Обратный диапазон и некорректное время не позволяют сохранить настройки.

## Пропуск дубликатов PACS

В **Настройки → Мониторинг** добавлена выключенная по умолчанию опция **«Пропускать дубликаты, отклонённые PACS»**.

- Явный ответ `Duplicate SOP Instance` либо явное сообщение Error Comment о дубликате экземпляра, объекта или исследования завершает доставку без ошибки и повторных попыток.
- В деталях показывается **«Дубликат пропущен»**, ответ PACS сохраняется в журнале.
- Для очереди и общей статистики такая доставка считается завершённой (`Sent`); это не означает, что PACS принял новые данные.
- Исходный файл сохраняется даже при включённом удалении/архивировании, в том числе если остальные PACS приняли его успешно.
- `Duplicate Invocation`, общий отказ без сообщения о дубликате и сетевые ошибки сохраняют обычную обработку.
- Первая попытка C-STORE каждого объекта нужна, чтобы получить ответ PACS. Сопоставление с конкретным PACS на объекте пока не проверено.

## О программе

Обновлены номер версии и сведения об изменениях. Проверка обновлений показывает полный номер `1.5.5`.

## Обновление

1. Полностью завершите прежний DicomMover, включая значок в системном трее.
2. Замените EXE в папке программы, сохранив `appsettings.json`, базу `data` и прочие рабочие файлы. Если EXE имел другое имя, сохраните прежнее имя для ярлыков и автозапуска.
3. Запустите DicomMover 1.5.5. Настройки и история сохраняются; новая настройка пропуска дубликатов по умолчанию выключена.

Для нового запуска распакуйте ZIP в отдельную папку и запустите `DicomMover.exe`. PACS и папки настраиваются вручную либо импортируются из JSON.
